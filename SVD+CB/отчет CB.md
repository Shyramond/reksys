# Модель Content-based (Metadata/Images)
**Суть:** Модель ищет визуальное и текстовое сходство. Если вы играли в «RPG про рыцарей», она найдет все остальные «RPG про рыцарей» в базе.

| Метрика | Значение | Комментарий |
| :--- | :--- | :--- |
| **Precision@K** | 0.2980 | Средняя точность. Часто находит «клонов», которые пользователю не нужны. |
| **MRR@K** | 0.3850 | Ранжирование среднее. |
| **Novelty** | 8.2400 | **Низкая.** Рекомендует очень похожие, предсказуемые хиты. |
| **ILD (Diversity)** | **0.2210** | **Очень низкое разнообразие.** Весь список может состоять из одинаковых игр. |
| **Coverage** | **0.8850** | **Максимальное покрытие.** Может порекомендовать любую игру, где есть теги. |
| **Personalization**| 0.9980 | Абсолютно уникальные списки под каждый конкретный айтем. |

**Анализ Content-based:**
*   **Сила:** Невероятное покрытие каталога. Это единственная модель, которая решает проблему «холодного старта» для новых игр. Если у игры есть обложка и теги — она будет в рекомендациях.
*   **Слабость:** «Эффект эха» (Filter Bubble). Если пользователь ищет шутер, он получит 10 очень похожих шутеров, что быстро надоедает (низкий ILD и Novelty).
*   **Вердикт:** Это «логичный» рекомендатель, который работает как продвинутый поиск по фильтрам.
