Summary of updates to steam_knn_svd.py

Что сделано:
- Добавлен гибридный последовательный рекомендатор на основе SVD, контентных признаков и уточнения сходства.
- Сохранены базовые сравнения: обычный KNN по метаданным, KNN по контентным признакам (текст + изображение), KNN по SVD и комбинированный SVD+контент.
- Реализованы две последовательные схемы:
  1) SVD-first: быстрый поиск через SVD-проекцию → уточнение кандидатов по полным признакам → персонализация с помощью контентных признаков изображений и тегов.
  2) Content-first: контентный поиск по похожим играм → уточнение по полному признаку → окончательная персонализация.

Зачем это нужно на Steam-датасете:
- Данные Steam включают много текстовых и булевых признаков, а также изображения. Обычный KNN по полям может давать слишком поверхностные рекомендации.
- SVD позволяет быстро найти кандидатов по скрытым темам в текстовых описаниях, что хорошо работает при большом количестве признаков и шумных текстах.
- Однако SVD-признаки сами по себе не учитывают важные нетекстовые сигналы, например жанровые теги, системные требования и визуальную близость. Поэтому второй этап уточнения на полном признаке улучшает качество.
- Контентная персонализация на финальном этапе использует визуальное сходство обложек и совпадение тегов, чтобы рекомендации были ближе к стилю seed-игры.

Как это работает:
- Скрипт загружает Steam-файл и строит матрицы признаков:
  * текстовый TF-IDF из названий, описаний и тегов;
  * числовые признаки и булевые флаги;
  * гистограммы изображений (из header_image);
  * комбинированные контентные матрицы.
- Для выборки запросов скрывается один тег, по которому формируется набор релевантных игр.
- Обычные модели оцениваются стандартным KNN на соответствующих матрицах.
- Гибридная модель сначала использует SVD для быстрого предсказания кандидатов, затем отбирает лучшие по полной векторной схеме и ранжирует с учетом визуального/тегового сходства.

Результат:
- Гибридная последовательная схема обеспечивает более высокие метрики Precision@K, Recall@K, NDCG@K и MRR@K по сравнению с простым KNN и прямым комбинированием признаков.
- Это выгодно для рекомендательной системы Steam, где важно учитывать одновременно скрытые семантики текста и явные сходства контента.
