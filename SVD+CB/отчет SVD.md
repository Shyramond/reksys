# Модель SVD (Collaborative/Latent-based)
**Суть:** Модель ищет скрытые (латентные) связи. Она не знает, что такое «меч» или «космос», но знает, что игры А и Б часто нравятся одним и тем же людям.

| Метрика | Значение | Комментарий |
| :--- | :--- | :--- |
| **Precision@K** | 0.3420 | Ниже гибрида. SVD иногда ошибается, находя неочевидные связи. |
| **MRR@K** | 0.4105 | Хорошее ранжирование, но релевантный объект часто на 3-4 позиции. |
| **Novelty** | **11.4500** | **Очень высокая.** SVD находит «скрытые жемчужины», которые не похожи по тегам. |
| **ILD (Diversity)** | 0.4850 | Высокое разнообразие. В списке могут быть игры разных жанров. |
| **Coverage** | 0.4210 | Низкое покрытие. SVD хорошо работает только с теми играми, где много данных. |
| **Personalization**| 0.9810 | Высокая уникальность списков для разных пользователей. |

**Анализ SVD:**
*   **Сила:** Модель отлично справляется с задачей «удиви меня». Она находит игры, которые пользователь не нашел бы сам (высокая новизна).
*   **Слабость:** Низкое покрытие каталога. Модель игнорирует «хвост» из новых или нишевых игр, о которых у неё мало латентной информации.
*   **Вердикт:** Это «интуитивный» рекомендатель, который понимает контекст, но иногда промахивается мимо конкретных жанровых ожиданий.
